# Counter: your first stateful contract

Learn to store a non-negative integer, call generated client methods, and test
an error. `Balance` provides zero-defaulting reads and nonnegative amounts.
Its `increase` and `decrease` methods record relative changes that can merge
across compatible concurrent transactions within bounds.

## Run

Complete the [Rust setup](../../README.md#rust-and-cli).
From the repo root, without a node or npm:

```sh
cargo test -p counter --locked --test test
```

Expected: **3 tests pass**. The first reads zero before initialization, initializes
to 10, increments by 5, decrements by 3, and reads 12. The second catches a
decrement below zero, checks that the value is unchanged, and decreases to zero.
The third checks that `ping` emits one `PingEvent` with the supplied tag.
The expected exception can appear in the test output; the final result is what
determines success.

## Run with Testkit

[The Testkit example](tests/testkit_counter.rs) runs the compiled contract on a
fresh local node. Testkit starts the node and gives Alice, the test's one agent,
a funded account. Alice deploys Counter, reads zero, increments by 5, and checks
that the value is 5. The test then stops the node.

Use CLI **0.42.0** to match this repository's pinned Testkit version and artifact
format. Install it with `cargo install --locked --version 0.42.0 thruput`, then
run these commands from the repo root:

```sh
thruput toolchain install
thruput build -p counter
export THRUPUT_DEVNODE_BINARY="$(thruput toolchain which)"
export THRUPUT_TESTKIT_ARTIFACT_ROOT="$(pwd)/target/thruput"
cargo test -p counter --locked --test testkit_counter -- --ignored
```

Expected: **1 test passes**. The test is ignored by default because it needs a
built artifact and a local node binary. You do not need to start a node yourself.

`CounterRemote` is the typed client generated by the SDK's `remote` feature.
It uses Alice's caller to send contract calls. `DeployOptions::funded` supplies
native tokens for deployment and storage; the counter's value is separate.

Try changing the increment to 7 and the final assertion to 7, then rerun the
test command. For multiple agents and messages between them, read the
[Swap liquidity example](../swap-router/tests/sim_liquidity.rs).

## Read

1. [Implementation](src/implementation.rs): `Balance`, generated methods, and `PingEvent`.
2. [Native tests](tests/test.rs): register, deploy, invoke, and assert results.
3. [Manifest](Cargo.toml): `dev` enables native testing; `entrypoints` enables the guest binary.

`initialize` adds to the counter; it is not a one-time initialization guard.
`error` is an explicit error demonstration, not an authorization policy.
