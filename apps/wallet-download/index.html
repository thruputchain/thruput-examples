Install in Chrome

  1. Extract the ZIP. Keep the thruput-wallet folder on your computer.
  2. Open chrome://extensions and turn on Developer mode.
  3. Click Load unpacked and select the extracted thruput-wallet folder.
  4. Pin the extension, create a test wallet, select Devnet, and click Request test HOG.
